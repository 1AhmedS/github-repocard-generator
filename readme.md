# 📌 GitHub Repository Card Generator

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/1AhmedS/github-repocard-generator/pulls)
[![Maintenance](https://img.shields.io/badge/Maintained%3F-yes-green.svg)](https://github.com/1AhmedS/github-repocard-generator/graphs/commit-activity)

> Advanced tool for creating attractive and highly customizable GitHub cards for README files and websites.

## ✨ Key Features

- 🎨 Modern design with light and dark mode support
- 🖌️ Full customization of colors and fonts
- 🌐 Bilingual interface (Arabic/English)
- ⚡ Quick card generation with live preview
- 📋 One-click copy of HTML or Markdown code
- 📱 Responsive design for all screen sizes

## 🚀 Quick Start

### Method 1: Local Development
```bash
# Clone the project
git clone https://github.com/1AhmedS/github-repocard-generator.git
cd github-repocard-generator

# Install dependencies
npm install

# Start the server
npm start
```
Then open your browser to:
```
http://localhost:3000
```

## 🛠️ How to Use

1. Enter project information (name, description, language)
2. Customize appearance (colors, themes, fonts)
3. View live preview of changes
4. Copy HTML or Markdown code
5. Add the code to your README.md file

## 🎨 Customization Options

- **Colors**: Customize all card colors
- **Themes**: Full support for light and dark modes
- **Fonts**: Support for both Arabic and English fonts
- **Statistics**: Display stars, forks, and issues count
